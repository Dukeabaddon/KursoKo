# Questionnaire copy rubric (SHS / SCENE)

**Audience:** Senior High School students (~15–17), Philippines.  
**Scoring:** RIASEC codes unchanged — copy only.

## SCENE formula

```
[Simple verb] + [Concrete thing] + [Familiar moment]
```

| Slot | Rule |
|------|------|
| Verb | Everyday action: fix, count, draw, convince, sort |
| Object | Visible thing: bike chain, snack list, poster |
| Setting | Teen life: home, class, school fair, barkada |

**Reading level:** Grade 6–7 text for Grade 9–10 users.

## Stem templates (rotate)

- Which would you rather do?
- Which sounds more fun to you?
- Pick the one you'd enjoy more.

**Never use:** technical, business, professional, role, internship.

## RIASEC behavior (not job titles)

| Code | Student feels |
|------|----------------|
| R | work with hands/tools |
| I | figure out why/how |
| A | make something new |
| S | help/connect people |
| E | lead/persuade/sell |
| C | keep things neat/correct |

## Anti-patterns

- Job titles, adult workplaces, STEM prestige jargon
- Contest/graded frames, teacher chores
- Unequal "coolness" between A/B options
