## Style B layout (every slide 01–07)

```
┌─────────────────────────────┐ 1080×1080
│ TOP ~120px                  │ Headline #4B2C7F, Poppins bold ~40–48px
│ CENTER ~780px               │ Browser mockup, radius 20px, shadow
│ BOTTOM ~80px                │ Purple strip #4B2C7F, white text ~22–24px
│ corner                      │ K logo 48px white rounded square (optional)
└─────────────────────────────┘
```

**Style A** = browser mockup only, full frame, cream `#FDFCF8` — use if you skip headline strip.
